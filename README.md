## Current Projects

### [EventWatch — Python SIEM Prototype](https://github.com/Voooges/eventwatch-siem)
A local dashboard for importing and analyzing Windows security logs.

- Imports JSON and XML events and stores them in SQLite.
- Applies five detection rules covering login patterns, account creation, administrator group additions, and audit log clearance.
- Displays supporting evidence and exports alert reports.
- Includes 14 automated tests; successfully imported 500 real Windows security events.

**Status:** Working prototype; continuing detection validation and development.
